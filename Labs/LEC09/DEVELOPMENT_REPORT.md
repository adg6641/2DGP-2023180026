## 최종 검증 결과

| 항목 | 방법과 결과 |
| --- | --- |
| 문법 | `python -m py_compile` 통과 |
| 단일 파일 | 실행 코드·동작 데이터·검증 함수가 Python 파일 하나에 포함됨 |
| 프레임 데이터 | `--validate`로 ID·크롭·기준점·프레임 시간 검증 통과 |
| 원본 커버리지 | 소닉 영역의 불투명 픽셀 45,746개 대조, 누락 0개·중복 0개 |
| 시각 검수 | pico2d가 렌더링한 10개 동작별 프레임 검수 이미지를 원본과 대조 |
| 출력 크기·잘림 | SDL이 반환한 창 크기 1200 × 800 확인, 전체 76프레임의 4배 출력 영역이 창 내부에 있음 |
| 시간 규칙 | `--self-test`로 모든 프레임의 5회 반복, 재생·휴식 경계, 다음 동작·전체 순환 검증 통과 |
| 시간 지연 | 모든 동작을 출발점으로 한 Decimal 기준 500개 지연 사례 통과 |
| 단일 프레임 동작 | 한 프레임으로 만든 별도 검증 동작도 5회·1초 휴식·순환 통과 |
| 실제 전체 순환 | 실제 창 약 97초 실행, A01~A10 두 번 순환 후 A01 재진입 확인 |
| 실제 프레임 재생 | 전체 순환 실행에서 모든 동작의 모든 프레임이 각 반복 회차에 렌더링됨을 기록 |
| 휴식 화면 | 실제 렌더러 픽셀 해시를 비교하여 각 휴식 구간의 마지막 프레임·위치 유지 확인 |
| 종료 이벤트 | 실제 SDL 이벤트 큐로 ESC·창 닫기를 각각 재생·휴식 중 주입하여 4가지 종료 사례 통과 |
| 오류 처리 | 이미지 누락·손상 및 잘못된 크롭에서 파일·동작을 식별하는 안내와 캔버스 정리 확인 |
| 실행 경로 | 저장소 루트와 `Labs/LEC09`에서 실제 창 실행 통과 |
| 커밋 기록 | 구현 24개 커밋 모두 실제 코드 변경과 한글 메시지 포함 |

실제 창 검증에서는 실행 루프의 화면 갱신 시점을 계측하여 프레임·반복·상태를 수집하고 SDL 렌더러의 픽셀을 읽었다. 검수 이미지와 일회성 계측 스크립트는 임시 폴더에서 생성했으며 실행 필수 파일에 포함하지 않았다. 종료 검증은 운영체제 입력 자동화가 아닌 실제 SDL 이벤트 큐 주입으로 수행했다.

## 실행 및 재검증

저장소 루트에서 실행한다.

```powershell
python Labs/LEC09/sonic_animation_viewer.py
python Labs/LEC09/sonic_animation_viewer.py --validate --self-test
python Labs/LEC09/sonic_animation_viewer.py --smoke-seconds 3
```

`Labs/LEC09`에서 실행할 때는 파일명만 사용한다.

```powershell
python sonic_animation_viewer.py
```

구현 커밋 목록은 다음 명령으로 확인할 수 있다.

```powershell
git log --reverse --oneline 6f4872b..e034f13 -- Labs/LEC09/sonic_animation_viewer.py
```

이번 작업의 실행 코드 변경은 `Labs/LEC09`에 한정했다. 기존 `Labs/LEC08_Animation/character_runs.py`의 사용자 수정은 커밋에 포함하지 않았다.
