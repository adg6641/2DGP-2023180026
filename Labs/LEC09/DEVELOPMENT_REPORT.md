- 종료: ESC 또는 창 닫기

## 실행 및 재검증

저장소 루트에서 실행한다.

```powershell
python Labs/LEC09/sonic_animation_viewer.py
python Labs/LEC09/sonic_animation_viewer.py --validate --self-test
python Labs/LEC09/sonic_animation_viewer.py --smoke-seconds 3
```

`Labs/LEC09`에서 실행할 때는 파일명만 사용한다.

```powershell
python sonic_animation_viewer.py
```

구현 커밋 목록은 다음 명령으로 확인할 수 있다.

```powershell
git log --reverse --oneline 6f4872b..e034f13 -- Labs/LEC09/sonic_animation_viewer.py
```

이번 작업의 실행 코드 변경은 `Labs/LEC09`에 한정했다. 기존 `Labs/LEC08_Animation/character_runs.py`의 사용자 수정은 커밋에 포함하지 않았다.

## 이동 기능 추가: 25~27단계 당시 기록

프레임이 바뀌어도 캐릭터 위치는 중앙에 머물던 기본 버전에 이동을 추가했다. 각 동작의 경과 시간으로 프레임과 위치를 계산하여 동일 프레임을 표시하는 동안에도 움직이게 했다. 아래 이동 목록은 25~27단계 당시 구현이며, 최종 행별 규칙은 마지막 절을 따른다. 전체 48초 순환과 5회 재생·1초 휴식 규칙을 유지한다.

| ID | 이동 속도 | 경로 |
| --- | ---: | --- |
| A01 | 100픽셀/초 | 걷기와 회전, 수평 왕복 |
| A02 | 220픽셀/초 | 달리기, 수평 왕복 |
| A03 | 300픽셀/초 | 전력 질주, 수평 왕복 |
| A04 | 0 | 회전 진입, 중앙 제자리 |
| A05 | 180픽셀/초 | 구르기, 수평 왕복 |
| A06 | 300픽셀/초 | 고속 달리기, 수평 왕복 |
| A07 | 380픽셀/초 | 초고속 달리기, 수평 왕복 |

속도는 확대된 창의 픽셀/초이다. 각 동작의 시작 기준점은 `(600, 400)`이고, 기본 자산에서 수평 기준점은 264~936 범위로 이동한다. 관찰 영역은 가로 160~1040, 세로 200~704로 확대해 점프 공간을 확보했다. 좌우 경계에서는 남은 이동 거리를 반사하고 스프라이트를 반전한다. 휴식 전체 구간에는 재생 완료 시점의 프레임·위치·방향을 고정한다.

| 실제 휴식 화면 | SDL 렌더러의 픽셀 해시로 두 번 순환의 각 휴식 구간이 고정됨을 확인 |
| 실제 시각 검수 | 경계 반사 후 왼쪽을 향한 달리기와 공중 점프를 실제 렌더러 캡처로 확인 |

이동 버전의 실제 창 계측 및 검수 이미지는 임시 폴더에서 생성했다. 실행 파일에는 동작 데이터와 이동 검증 함수를 포함하며 추가 실행 자산은 필요하지 않다. 요구사항·인수 기준 개수와 MD의 UTF-8 한글 표기를 확인했다.

## 최종 행별 동작·설명·배경 마무리
