# 소닉 애니매이션 뷰어 작성

개발언어 python
라이브러리 pico2d
파일이름 sonic_animation_viewer.py
단일 파일로만 작성
스프라이트 이미지 sonic-sprite.png
창 크기 1200 × 800 픽셀

기능:
이미지의 모든 동작을 재생.
동작별 5회 재생, 1초 쉬고, 그 다음 동작 재생.
모든 동작을 다 재생한 후, 다시 무한 반복

걷기, 달리기, 구르기 등 이동이 포함되는 애니메이션은 프레임 재생과 동시에 화면 위치도 이동.
공중 동작은 수평 이동과 점프 궤적을 함께 표시.
관찰 영역 끝에서는 방향을 반전하고, 소닉이 이동 방향을 바라보도록 표시.
1초 휴식 중에는 마지막 프레임, 위치, 방향을 유지.
다음 동작은 화면 중앙에서 새로 시작.

화면 대비, 이미지가 잘 보이게 원본의 4배로 확대.

개발방법:
한번에 다 개발 x. 
단계별로 구현해서, 커밋을 그때그때 할 수 있도록
최소한 개발단계는 20단계 이상으로 진행.
커밋 메시지의 제목과 본문은 한글로 작성.
