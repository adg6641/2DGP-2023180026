# 검증 기록

## 최종 수정: 캔버스에서 오른쪽 이동

- 걷기 100px/s, 달리기 180px/s, 점프 120px/s의 오른쪽 이동과 화면 경계 순환 구현
- 점프의 포물선 상승/착지, 공격 한 회당 60px 전진 돌진 구현
- 자동 1초 정지와 SPACE 정지 때 위치도 고정, R 재시작 때 시작 위치로 복귀
- 모든 가변 크기 프레임과 칼/잔상이 이동 중에도 화면 경계 안에 있는지 검사
- 자동 검사 10개 통과, 26포즈와 4정지 상태의 실제 렌더링 확인
- 실제 창에서 전체 한 순환을 넘는 20초 이동 재생 확인
- 이 변경을 담은 새 커밋 1개를 추가하여 과제 개발 커밋은 총 27개
